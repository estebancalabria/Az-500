# Notes

* “Azure AD integration must be configured at cluster creation time. It cannot be enabled after deployment.”
  
* Azure Arc extiende el plano de control de Azure Resource Manager hacia infraestructura fuera de Azure —on-premises, otras nubes o el edge— proyectando cada máquina física o virtual como un recurso Azure con identidad propia, sin migrar ni mover la carga de trabajo, para que sobre ella se puedan aplicar de manera uniforme gobernanza (Policy, RBAC, tags), monitoreo, y superficies de seguridad como Defender for Cloud.
